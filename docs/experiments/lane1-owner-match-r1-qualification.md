## Parameter-wide topology invariant

The reuse is valid for every parameter combination admitted by its constructor
requirements, not only this ABC profile. With registeredIssueExecute enabled,
IntegerBackend assigns the lane entry directly from executingOperands(lane).entry
(the registered execution payload). With parallelIssuePayload enabled, the raw
completion token is assigned directly from entry.renamed.token without a valid
mux. That completion payload is then assigned directly to ledger.complete(lane).
Every later alternative producer or parallel-completion arbitration override is
inside the elaboration-time lane == 0 branch. Lane one therefore retains the same
raw captured token regardless of branch-valid gating, completion-valid gating or
acceptance. Width two and tagBits 64 bound the query interface and comparison.
The unchanged registered row tag writes in the ROB and queue derive from the same
accepted rename token. Retire and kill retain those tags; reallocation overwrites
both from the new accepted token. Occupied guards the stale predicate before it
can cancel an empty execution slot. These source invariants establish the design
argument; the runtime token/equality assertions provide additional dynamic
witnesses rather than being the sole basis of the proof.

only one exact internal binding renamed from
`_io_savedLoadDisjointFromFrozenStart_T_20` to `_io_savedLoadDisjointFromFrozenStart_T_23`:

complete file byte-identical; its expression and use are checked. Raw file
inequality remains recorded. No general identifier normalization is used.

The lane-1 cancel cone loses all 32 queue-token register leaves (16 indices and
16 tags). The query depends only on sixteen registered ROB tag rows and the
lane-1 captured 4-bit index / 64-bit tag. Raw completion token fields connect
directly to the registered execution payload. Completion valid/accepted, live,
head, count, done and recovery do not feed back into the query. The actual final
ROB acceptance reuses the same sole 64-bit equality and retains its old live/age
qualification. The exported Boolean has exactly one backend consumer: lane-1
cancel. Occupied masking and original kill handling remain intact.

inventories match: IntegerBackend 727 registers / 7,334 bits; RenameRob 248 /
