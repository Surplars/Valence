配置为单发射 RV64IM、fpga8/timing-cuts/dsp-tiled、32 KiB I-cache + 32 KiB D-cache、64 字节行、直接映射、写穿、BTB128。F/D/FPU 关闭，16 个 DSP 属于整数乘法；hashed 索引与 fastDivision 默认关闭。没有额外 CPU monitor、AXI/TileLink 系统互连或 UART/CLINT/PLIC/DDR 控制器；固有 CSR 计数器、退休/异常/命中等观察输出及两路 FiveStageBurstPort 访存接口保留。仿真外存与预测观察顶层不计入综合。

本批采用的 RTL 改动：

- IF 级增加一个 skid 槽，总容量 2，输入 ready 只依赖寄存占用。非满时 II=1，满后 pop 的下一周期恢复接纳；flush 优先清除所有权，已发出的外部请求仍按 pending/killed 契约排空。
- 预测器用局部 clear guard 隔离原始有效位，保留精确失效边沿、次周期训练和 II=1；两位饱和计数器改为等价布尔表达式，没有添加 DONT_TOUCH。
- 缓存仅保存常量可缓存窗口内变化的 tag 位，同时保留精确全地址窗口准入。默认 49 位缩为 13 位，双方共去除 36864 个冗余 tag 位；未使用有碰撞的缩短 tag。I1CacheTags 按最多 64 行分 bank，捕获本 bank 行号、局部比较，再选择单比特结果；有效位仍由缓存统一持有，容量、命中延迟及 II 不变。
- ID/RR/EX/ADDR 宽载荷在本级空闲或释放时自然采样，实际 valid 和信用仍只由真实转移更新。RF 碰撞数据与元数据自然采样，responseValid/held 保持读写碰撞、停顿和复位契约，移除晚 ready 对大批数据 FF 的门控。
- PC 预测候选与恢复/重放使用平坦 one-hot 选择，移除归并预测字后的级联 mux。地址加法采用 16 位并行进位块；分支未对齐的 tval 在已有 ADDR 级从已捕获目标恢复。未增加架构流水级，也未改变 MDU 时延。

后续 prepared ALU 控制、提前捕获缓存有效位、PC XOR 合并以及来源优先级重排等尝试未成为默认实现。相关失败版本位于 evidence 根下 `source-natural-r6/r7/r8` 和对应物理目录；不能把这些版本的局部逻辑改进当作 PPA 收益。强制复制试验已按用户要求停止并排除，新加的 DONT_TOUCH 已移除。选定结果只使用与基准一致的普通自动实现流程。

此前原生 Verilog 检查暴露了 firtool 1.135.0 的聚合掩码 RAM 导出问题：同尺寸 I/D RAM 的掩码粒度合并后，I-cache 回填只写首字节。当前使用的导出入口加入 `--lower-memories`，先拆成 ground byte RAM；没有给未初始化存储强制置零。未修正导出的早期物理结果不具备功能资格，已排除。

物理范围是完整生产缓存核加统一端口捕获夹具 I1Core300Context：每个输入/输出叶端口和复位都经过边界寄存器。FF 总数包含这部分固定夹具，CPU 与夹具在层级资源报告中分列。夹具用于状态间时序表征，不是可直接接入 SoC 的弹性适配器；外部 pad 时序和整板资格未声明。
