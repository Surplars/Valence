# I1 总线、CMU、H 与 Spinor 接入（2026-11-05）

当前基线 R5 的功能和最终物理结果已冻结：CPU/VPU/system setup 为 -0.622/-0.003/+0.069ns，整机尚未达到 300MHz。R6 完成 H 返回路由、缓存长度分类与 VPU 预览比较的结构修改，功能/IPC 全通过，但自动 URAM 映射使取指输出延迟增加；R6 物理运行保留证据、不提升为最佳版。当前 R7 将同一 Icache 数据明确分为八个字节/分类存储，保持容量和单周期命中。三域仍独立、目标均为 300MHz。

## 实际装配范围

- RV64 单发射 IMAFDC CPU，fpga8，32 KiB I/D cache、BTB128、DSP tiled MDU；H 可选且默认关闭。
- 现成 Spinor `e151f80e1da3a566d1a6ff5157052757fac0ddcb`，VLEN128/ELEN64、host FCSR。原 clone 保持干净；明确的本地替换文件参与 `SpinorI1` 编译。CPU owns FCSR，VPU owns VRF/向量 CSR，80 位 token 完整保留。
- CPU/VPU 六路命令及数据 mailbox，I/D 两路 TL CDC，共享 atomic/D-cache 保持向量存储对 LR/SC 的失效语义。
- 两主机 TileLink fabric、注册地址路由、TL→AXI outstanding bridge（2 slots、1 write、32-bit address/4-bit ID）、UART、timer、PLIC、CMU。DDR/MIG、ROM、调试/网络和板级时钟 IP 不在本次范围。
- CPU/VPU 可独立排空、停钟、外部唤醒；VPU 待处理命令可唤醒。CMU/system 常开，CPU/VPU 停止时保留 cache、VRF、FCSR 和 guest CSR。生产 FPGA wrapper 使用真实 BUFGCE，GSIM 用独立顶层时钟驱动同一 CMU 控制闭环。
- H/VS CSR、V 模式、trap/xRET/委托/虚拟 IRQ、HLV/HLVX/HSV、HFENCE、VS Sv39 + G Sv39x4、标量/向量访存 guest fault 元数据已接入 CPU。H profile 宣告 misa.H；Spinor 原生子集仍不宣告完整 misa.V。

## 物理结果与待验收项

器件 `xczu15eg-ffvb1156-2-i`，300 MHz（3.333333333 ns），setup uncertainty 0.100 ns、hold 0.080 ns。时钟未放宽，不使用全域 false path/clock group 或 multicycle 遮盖功能路径。CDC 只约束明确的同步器第一拍、Gray、持有稳定的 mailbox 数据及 BUFGCE CE，并检查覆盖与拓扑。

|---|---:|---:|---:|---:|---:|---:|---:|
| system R1，H 关闭，原始生产端口 OOC | 48581 | 32505 | 16 | 35 | -0.264 ns | +0.012 ns | -2.301 ns |

R1 原始 AXI 端口的合成输入 min=0 产生大量 hold 修复与共享网络布线延长，不能将其系统 WNS 与端口上下文的 R2 直接当作 RTL 改善。R2 的 39,761 总 FF 包含 624 个顶层测试寄存器，DUT 39,137 包含 10 个时钟后端 FF；顶层 84 个 LUTRAM 为 DUT 逻辑，不得当作 fixture 扣除。

R2 纯 DUT 审计 `audit-dut/internal_result.tsv`：CPU 5,498 个 setup 负端点、VPU 0、system 15；三域 hold 分别 +0.010/+0.010/+0.004 ns，无内部 hold 违例。原含 fixture 表的 system hold -0.010 ns 落在输出测试寄存器，保留原始报告但单独计数。

R3 成批改动：复用待取指 offer PC 保存预测地址、压缩 guest fault GPA 元数据、VS IRQ/vectored trap 的低位计算，以及 CMU 常量权限掩码前移。全部保留精确 owner、字节权限、反压、异常和独立断言；没有增加架构流水级。R3 routed LUT 比 R2 下降 60、DUT FF 下降 272；CPU setup 改善 0.112 ns，负端点由 5498 降至 4721，VPU/system 均为 0。三域内部 hold 分别 +0.006/+0.010/+0.010 ns，内部 hold 负端点均为 0。端口测试 fixture 的 system hold -0.011 ns 单独保留，不纳入 DUT 内部通过结论。详细资源与全部报告 hash 见 `physical-summary.json`。CPU 尚未通过 300 MHz。

## 新增边界补测与 R4 否决

物理地址提前准备的独立补测发现：`FiveStageAddressTranslation` 的局部 send 相位只检查 PMP/atomic，遗漏新 HLVX R+X、向量正常内存限制及 VS 第一级 GPA 旁路，和保留的原始 `nextState` 不相等。原断言在向量 MMIO 拒绝时捕获该错误。该遗漏也影响 R3；先前 11 组正常/guest 页故障程序没有覆盖这个 M/Bare 向量拒绝分支。R4 已停止 Vivado，不把已有综合输出作为合格候选。

首次补测另有测试层级错误：CPU 负责执行阶段对齐异常，MMU/PMP 允许非对齐范围输入。原失败、源码与解释保留在 R4 `bare-permissions/test-contract-correction.json`。修正后的测试要求非对齐请求经过独立慢授权 owner，继续独立拒绝越界和向量 MMIO，保持真实总线错误与反压检查；没有改动 oracle 来屏蔽实际相位错误。

当前具体装配：CPU IMAFDC+S/U+H，`misa.H=1`；Spinor 向量通路开启但 `misa.V=0`，尚未宣告完整 RVV。专用 CPU monitor、BootROM、DDR/MIG 均未实例化；保留 mcycle/minstret 与退休观察。若使用 PS DDR，PL 可经 PS AXI HP 接口使用其硬 DDR 控制器，不需另实例化 PL MIG；PS DDR/端口/启动尚未接入。本轮 AXI 输出仍为 DDR 窗口偏移，后续必须明确 PS 物理地址映射。

## R6 与 R7：取指存储组织及完成比较

R6 用已登记的 direct/host/VS 所有者并行选择 H 响应，把 8bit parcel classes 与 64bit IF 数据一起存储；Spinor 在归一化异常字段前并行比较原始完成字段，完整 normalized packet equality 作为独立 GSIM 断言保留。没有新增流水级。GSIM 的 11 组真实 H/V/CMU 客体、34269 项状态、326 次 CMU 访问、56 项物理地址检查，以及新 cache 前缀/回填/反压/连续命中检查和负例均通过。固定/真实压缩 CoreMark 全部 rows 与 R12 相等；11 组整机程序的 CPU/system 周期、停钟统计也与 R5 逐行相等。

R6 综合为 54281 LUT、39124 总 FF（含 624 fixture FF）、8 BRAM36、1 URAM、35 DSP。与 R5 同口径综合相比减少 242 LUT，增加 28 FF；一个 URAM 替代原八个 IF BRAM，原始存储容量相同。URAM 未注册输出约 2.038ns，较原 BRAM 约 0.919ns 慢，布局估算显示不利于 300MHz。此处不把综合/布局估算替代最终 routed 结果。

R7 保留本批 H/V 结构改进，将 IF 存储明确拆为八个并行 4096x9 lane，每个 lane 保存一个 byte 和一个分类 bit。读取后仅静态拼接，不增加 hit 周期、队列、复制容量、强制扇出或时序例外。等待新 GSIM 与物理确认。
