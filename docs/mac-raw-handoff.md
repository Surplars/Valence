# Opt-in MAC raw-clock handoff

The production defaults remain OFF. `fpga/next/board_near_term_a_raw_handoff.py` is the explicit near-term A plus MAC platform entry: A's exact 68 native options plus `--tri-speed-raw-clock-handoff`. The added `triSpeedRawClockHandoff` field is the 89th platform field; all 172 CPU parameter names, order and values remain unchanged. Existing A and exact64 loaders accept only an exact current-source OFF bridge. Their historical manifests and receipts remain unchanged.

The handoff samples a 12-bit tuple on the raw falling edge, then registers the 11 RX bits on the enabled managed RX rising edge. TX uses the falling sample directly. The source adds 23 scalar state bits. RX adds one enabled cycle with initiation interval one; TX adds no cycle. These are component latency/state results, not a measured FPGA frequency or resource claim.
