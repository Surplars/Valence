# Aligned halfword RAM packing

This third isolated optimization preserves the qualified sum16 and CRC changes. After the original prefix aligns destination RAM, an even source uses four aligned GCC may_alias halfword loads per8bytes and the existing aligned volatile64-bit RAM store. Odd sources retain byte packing. Prefix, tail, image-range checks and return codes remain unchanged. The target is explicitly little-endian; no overlapping-copy contract is added.

Run `python3 scripts/test_netboot_store16.py --out build/netboot-store16-native`. Existing GCC-compatible tools with ASan/UBSan are required; `--cc` selects one and `--dry-run` only checks source identity/prints scope.
