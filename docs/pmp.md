# 物理内存保护合同

`MachinePlatform` 在 `MappedMachineCore` 中启用16条目PMP；`OooParams` 也允许显式选择8条目，
独立裸核/机器核默认不启用PMP。实现按56位物理地址、4字节最小粒度处理，支持OFF、TOR、NA4、NAPOT。
M态提供 `pmpcfg0`、`pmpcfg2` 和 `pmpaddr0` 至 `pmpaddr15`；保留配置位读零，
不支持的W=1/R=0组合写后清除W。锁定条目的配置和地址不可写；若后一个锁定条目为TOR，
它使用的前一条地址也不可写。PMP CSR写入只在ROB队首发生。

取指两条lane分别检查执行权限；前端还在发出每个取指包前，对两个32位字生成许可掩码。
两字均允许时保持原64位快速路径；跨权限边界时，只请求允许的32位字；两字都被拒绝时
ROM不读存储阵列，TileLink桥不发Get，而是返回带两位错误的空包。LSU在发起请求、
写缓冲插入或转发之前检查有效权限。
LR检查读，SC检查写，AMO检查读写；MPRV只改变M态数据访问使用的权限，MRET下降到S/U态时清除MPRV。
不允许的访问产生精确的取指、读或写访问异常，不向数据总线发出被拒绝的请求。
PMP CSR访问及MRET/SRET在ROB队首暂停新取指并等待旧取指完成；实际改变权限匹配的
PMP写入以及MRET/SRET刷新前端缓存包并重取，防止年轻指令沿用旧权限或旧特权级下的数据。
对OFF条目地址的准备写入若不影响相邻TOR范围，则不刷新前端。
区域比较在各条目并行执行，再选择编号最小的任意字节重叠条目；该条目必须覆盖访问的每一个字节。
未锁定条目对M态放行，锁定条目仍执行权限检查；实现PMP后，S/U态无匹配条目时拒绝访问。
规则依据[RISC-V特权规范的PMP章节](https://docs.riscv.org/reference/isa/_attachments/riscv-privileged.pdf)。

`make gsim-pmp-test` 使用独立C++区间模型验证重叠优先级、部分覆盖、TOR/NA4/NAPOT、
锁定M态、无匹配、最高编号条目及56位上界；包含16组定向和6000组固定种子随机访问，
并检查故意错误预期会被拒绝。
`make gsim-privilege-uart-platform-test` 用真实整机固件验证ROM和最高编号TOR锁定CSR、MPRV、
U态APLIC读写被拒、单个ROM指令禁止执行、M/S/U陷阱、串口输出及独立提交模型。
`make gsim-pmp-fetch-platform-test` 在双主TileLink整机上运行同一镜像，逐笔检查锁定后
没有Get覆盖禁执行字，且跨界允许字使用32位Get。独立取指测试另覆盖0/1/2许可掩码、
ROM部分读、桥响应背压和正常双字吞吐。Sstc及原双主负载回归覆盖既有路径。

当前平台没有Sv39页表转换或页级权限，也未覆盖通用I-cache、多hart或外部MMIO取指。
PMP比较器为并行组合逻辑，未增加正常双字取指或LSU请求的流水级；这一结构的FPGA
LUT/布线开销和Fmax仍需Vivado测量，GSIM周期数不能替代时序结论。

双主TileLink整机原RAM/DMA/原子固件的seed0周期由3611/5559/6694变为3614/5560/6695；
三类固件及三个背压种子均通过。正常取指保持64位Get，新增的PMP更新/特权返回排空使这三条
短启动程序分别增加3/1/1拍。独立前端测试的连续双字供给仍通过128个稳态周期；
这些GSIM数字只表示周期行为，不表示FPGA最大频率或复杂程序IPC。
PMP配置较密集的Sstc短启动程序在seed0下，小配置由180变为189拍、默认配置由231变为265拍；
这是权限更新和降权返回的前端排空成本，不能用它推断长时间运行负载的IPC。
