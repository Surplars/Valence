# 退役的 ChiselSim 测试

这些源码从 `src/test/scala` 原样移入，退出 Mill/SBT 默认测试发现。它们依赖 Verilator，
自 2026-09-18 起不再运行，也不提供恢复旧后端的构建入口。

包括旧核心、总线、缓存、外设、调试及 SoC 测试和配套工具。旧 `IonSoCSpec` 同时含展开与行为测试，
作为整套历史用例保留；当前配置检查和新核展开检查仍在活动测试目录。

已有工作区切换后若 Mill 仍发现旧编译类，执行一次 `mill -i clean IonSoC.test.compile` 再运行
`make test-scala`；无需清理 GSIM 工具链或全仓库产物。

这些用例尚未迁移到 GSIM，历史通过记录不代表当前覆盖率。后续接入对应模块时，先按规范审查期望值，
再编写 GSIM 驱动及独立模型，覆盖协议反压、恢复、异常和吞吐；不能仅移回活动目录或忽略失败。
