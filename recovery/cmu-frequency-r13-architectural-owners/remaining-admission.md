# Remaining admission and full-ACK prerequisites (source review)

These are source-derived integration requirements, not private netlist or physical probe results. The production platform still sets backend present=false and drain ACKs=0 (CommonMachinePlatform.scala:156–166).

1. Network launch and frame owners. CommonMachineFabric's visible stream-valid checks are not proof of hidden FIFO/frame/descriptor emptiness. Existing TriSpeedManagedGmac TX/RX stop and detailed local drain must be coordinated with packet DMA. Stop new DMA descriptor launches first, let accepted TX first-control/data/status and RX/memory work complete, then close MAC admission. Existing software RX_STOP can cancel queued descriptors, so it is not automatically a lossless runtime pause. Source locations: CommonMachineFabric.scala:269–280,300–325,452–478; TriSpeedManagedGmac.scala:161–179,282–287,372–392; EthernetPacketDma.scala:108,179–180,418–440.

2. Fixed-domain JTAG/DMI. Request.valid alone does not cover the response mailbox, a held DMI response or loader offered/awaiting RAM ownership. Stop at the fixed-debug acceptance point, drain already accepted requests and their responses, and retain later requests without accepting them or provide a defined wake policy. Link reset is not a runtime drain operation. Source locations: DebugDmiClockBoundary.scala:6–44; JtagRamLoader.scala:44–73,118–132,209–214; CommonMachineFabric.scala:454–456.

3. DMA/MMIO response consumption. Close command creation without blocking old control replies. Include arbiter-held requests, line requests/replies and posted packet work. RegisterClockDomainBridge sourceIdle is only true after the original source consumes its reply; export both relevant idle sides rather than an internal engine's idle. The CMU command's own software response must be consumed before its source clock can stop. Source locations: ClockDomainCrossing.scala:48–49,78–108; ClockRateControl.scala:69–73; CommonMachineFabric.scala:448–478.

4. DDR and background time snapshots. Combine the fabric's accepted AR→last-R/AW→B ledgers with both real Axi4ClockDomainBoundary transport-empty observations synchronized to their consumers. Neither alone is sufficient. Treat continuously refreshed time snapshots separately from transactional timer MMIO so a background mailbox does not create permanent artificial drain blockage. Source locations: CommonMachineFabric.scala:419–427; CommonMachinePlatform.scala:115–121; Axi4ClockDomainBoundary.scala:63–68; FixedTimebaseBoundary.scala:18–40.

5. External IRQ capture. APLIC pending preserves events already sampled by fabric. Pulses wholly inside a fabric-clock stop can still vanish. Each source needs a fixed/source/AON-domain retained event with consumption acknowledgment, or a documented source-held level contract. A two-flop level synchronizer does not solve arbitrary short pulses. Source locations: CommonMachinePlatform.scala:173–174; CommonInterruptFabric.scala:34–35; Aplic.scala:127–144.

All admission ACKs must be epoch-scoped, classify same-edge accepted work as old work, retain accepted owners through actual response consumption, and stay valid through the matching release. Real clock-close/open witnesses, managed-domain resumed edges, official generated DRP settings and physical validation remain additional gates beyond these logical owners.
