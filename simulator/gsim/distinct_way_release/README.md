# Distinct-way release component gate

This is the default-OFF C+R component correctness gate. It keeps same-set A serialization through E, the original offered-C priority, clean Release ordering and the existing DDR host's AW/pending-R fence. This component gate is not an executing CPU, a cycle-gain result, native resource census or timing qualification. The separately completed [same-source CPU pair, Sv39 companion and native evidence](../../../docs/experiments/distinct-way-release.md) establish those stated scopes while keeping the option default OFF.

`run.py` compiles the source-bound real `CoherentCacheHomeGsim` cache, `MixedCoherentLineHome`, bridge and independent backing/CPU byte model. OFF and ON differ only in `distinctWayRelease`. Checked-store PF, MRU insertion, LRU victim selection, two MSHRs/responses/WBs, two ways, 512 lines and the 128 KiB high-PA aperture are fixed. Construction reflection records the actual cache config, actual home Boolean, 0/2 issued bits and owner geometry. No existing generated model or behavioral pass is inherited.

The 18 bounded cases start with the main dirty-victim discriminator. ON must transfer exactly eight victim C beats while PF E remains held; OFF must retain the original cache request block. An invalid other way has zero C beats. A clean other way retains zero C beats before E and one clean Release afterward. The later demand A is held until PF E even in ON. Additional cases cover first-C/E and last-C/E on the same edge, a real flush during accepted overlap, and PF/demand denied-only or corrupt-only at D beat 0, 3 or 7. The real home first receives an AXI backing error and suppresses its own directory installation; a test-only wrapper then exposes the error on one chosen D beat/field, exercising independent engine aggregation without inventing a successful home owner.

The event-derived oracle tracks separate cache MSHR generations/full indices, engine source and saved tag, home sink/full directory index, and immutable cache WB generations/lines. Test-only source XOR-1 makes source identity independent. Legal setup holds an A after victim capture while a real DMA probe removes the other way, then resumes A. It establishes swapped cache/home way mappings before both collision cases and the late-Ack case. A delayed ReleaseAck must survive both old directory reuse and cache MSHR reuse. All C data words, normal/held CPU replies, directory full tags/owned bits, refill/error/E ordering, held C/A/D/E and final complete backing contents are checked. The negative directory mutation must be rejected by the independent full-line oracle.

Same-line, hit, write, uncached, virtualized, high-PA alias, unissued-PF, full-MSHR, full-response, pending-WB-target and flush offers are rejected. A real DMA probe exercises maintenance after the overlap. `postedConfig=None`: this component does **not** dynamically qualify posted live/intent gates. A B offered by this real home during a live Acquire is unreachable because maintenance drains Acquires; this gate does not manufacture an illegal B or posted proof. Those unchanged admission conjuncts remain source obligations, with any CPU/posted qualification separate.

The original DataPort has no token/epoch return ID: CPU identity is its full authored request and acceptance FIFO; MSHR generations and TL source/sink lifetimes are additional independent checks. Do not claim this component proves the CPU's full token/epoch retirement boundary.

The runner accepts one explicitly granted heavy slot. It runs tools serially, caps the sum of this source's Mill `out` and gate output at 250 MiB, retains at least 700 MiB free, and stops on timeout, source/tool drift, error or sanitizer report. The coordinator must additionally account for every other running task's remaining disk budget before starting. It uses the already restored tool receipt/JDK/cache; no installation or HOME change.

No build is launched by preflight:

    python3 -B simulator/gsim/distinct_way_release/test_cli.py

After a clean local source freeze and a coordinator slot grant:

    python3 -B simulator/gsim/distinct_way_release/run.py --tool-receipt /absolute/tool-receipt.json --output /absolute/fresh-gate-directory --slot-granted

A source edit invalidates a gate's source binding. Each revised attempt needs a fresh receipt. Model object reuse, if needed after a host-only repair, must match exact generated bytes, compiler and flags; this initial runner intentionally has no implicit reuse route.
