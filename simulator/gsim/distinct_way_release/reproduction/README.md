# Exact qualification helper sources

`source-inputs.json` lists 30 exact source inputs with SHA-256, byte size, source
path and the original recovery-workspace-relative restore path. Fourteen inputs
reuse identical files already tracked elsewhere; sixteen small source snapshots
are included here. The active component source remains in the parent directory,
and the merged native entry is `src/test/scala/ooo/DistinctWayReleaseNativeMain.scala`.

These are frozen replay inputs, not commands to run in place. Some snapshots refer
to the original qualification source and historical recovery layout. To replay,
choose one isolated recovery workspace, copy each listed source to its restore
path, and verify every SHA-256 before supplying the matching original pins,
classpath/tools, guest, source capsule and external evidence. A same-named file or
a newly generated model is not an identity match. The immutable snapshots retain
the original 33/140-field candidate contracts; the active merged source has
35/142/12 board/core/cache fields and both resource flags false for this experiment.

Durable input archives are referenced by Library identity in the experiment's
machine-readable evidence. The original CPU source capsule provides the small
transitive framework and restore map. The full unique case-19 ON raw archive holds
the original sidecars; fresh OFF 19 and ON 21 reuse the exact historical raw bytes
only after new DUT executions and per-file identity checks. No historical CPU pass
is inferred merely from copied helper source.

For the integration bridge, retain all three attempt runners and their matching
receipts. Attempts r1 and r2 intentionally remain failed export-path evidence. r3
uses the ordinary file emitter, verifies the repaired two-source overlay against
hash-bound fresh direct-scalac classes, emits both native sides serially and
requires literal equality of every raw native file. It does not substitute a
regular expression or structural normalization. The runner records every tool,
source, classpath, class, argument, gzip input and native output identity.

No build is launched by the source preflight:

    python3 -B simulator/gsim/distinct_way_release/test_cli.py

Hardware replay/export requires a coordinator-granted resource slot and the
original tool/runtime contracts. The source snapshots do not include generated
models, class files, ELF files, logs, raw traces or tool binaries. No full GSIM,
Verilator, mapped synthesis, STA or board result is implied.
