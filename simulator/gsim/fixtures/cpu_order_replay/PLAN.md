# Bounded executed-CPU replay and cancellation gate (not yet executed)

Use the already source-bound selected LSU4 OFF/ON board models. Both retain physical ingress, two D-cache MSHRs and DMA line depth4/yield0 (idle). The only A/B option is older-prefix retirement. Existing generated internal state is sufficient; no production edits or model probes are required.

1. A 64-bit DIVU computes 0x80400000 from 0x180c00000 / 3. The dependent older LD waits while a younger independent LD from the same address issues and completes. Because the DIV remains older in program order, neither load can retire before the late-address check. Require the actual replay selector's registered-next valid/token, then next-cycle pending valid/token, then accepted local inclusive recovery with that same full token. Independently check the committed guest PC sequence and read data, the checked older load's full token, and absence of canceled-generation retirement. The replayed younger LD must allocate a new generation and eventually retire normally. Check byte overlap independently from guest-specified addresses.
2. Place DIVUW, a forward taken conditional branch and four independent cold-line LDs in one 64-byte instruction line. DIVUW takes the actual 32-step implementation, while the unchanged external DDR model keeps its measured 32-cycle response schedule. Require all four distinct live LSU owners at accepted branch recovery; record which requests were already physical and which drain later. If this schedule does not produce the witness, report it and adjust the guest/specified legal external backpressure explicitly. Never assume future response timing or reduce the four-owner requirement.
3. Use only known RAM read regions, no stores except an independently checked final signature. Require every accepted physical response to match known memory and complete FIFO/full-token lineage; all canceled owners drain but never complete to ROB or retire. Terminal state requires zero live owners, requests, responses, all flow stages, pending physical replies and held handshakes.
4. Challenge missing selector/pending/recovery, incorrect full generation, omitted cancellation, canceled retirement, corrupted read data and premature terminal drain. These are checker-sensitivity controls; do not call them production RTL mutants unless actual RTL is changed and independently rebuilt.

Generated nets already present in the frozen OFF model include backend replayPendingValid and its NEXT value; replayPending token index/tag and NEXT; ordinaryLocalRedirectAccepted; localCandidate valid/full token; orderCheckValid/index/beat/lanes; exact full commit tokens and the existing full-token backend/flow probes. All field widths and receipt source/profile/tool/model hashes must be checked before any harness link.
