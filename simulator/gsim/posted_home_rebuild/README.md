The wrapper uses the actual NonBlockingCoherentLineCache, MixedCoherentLineHome, AtomicDataMemory CPU/DMA boundary, DataRequestBuffer, ordered TL bridge, arbiter and outstanding AXI bridge. True SRAM reads, DMA probe bytes and complete backing bytes after cache-plus-home flush check the result.

The first bounded gate tests merge/response-ticket reuse on ON and legacy behavior on OFF; real DMA changing the base before actual A; real home B/C DMA probing after install while the original CPU ACK is held, followed by DMA overwrite/no resurrection; and real clean/dirty victim C-last to new Acquire overlap with exact ReleaseAck held. Every claimed schedule needs nonzero observed events. Pre-A DMA need not cause a probe when the directory has no owner. Synthetic pre-A B and younger-refill/oldest-install schedules remain covered only by the earlier private-cache gate until real-home reachability is separately demonstrated.

The proof sidecar is an explicit committed-physical-store environmental premise. This fixture is not executing-CPU authority evidence, a whole-board test, FPGA PPA or a CPU throughput benchmark. The initial owner retains its original MSHR until all token and attached WB responsibility drains. No writeback reservation optimization is included.
