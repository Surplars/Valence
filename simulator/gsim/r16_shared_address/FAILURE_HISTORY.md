# Retained exploratory history and interpretation corrections

This is an explicit summary, not recreated raw output. Early exploratory runs were printed through the executor tool without separate raw log files. Do not cite this file as a byte-exact original execution transcript or claim every earlier source revision was preserved. Later `results-r1`, `results-r2`, `results-final`, `qualified-runtime-r1`, and the isolated negative retain their actual raw logs/traces. Initial, bare, and pre-kill host snapshots are retained under `host-build`.

1. First wrapper (`../r16-shared-address-gsim-r1`) emitted top-level Vec ports. Pinned GSIM generated scalar getters/setters against array members, which are invalid C++. This was found by inspection before model compilation, not a DUT failure. The complete generated r1 artifacts remain. R2 exposes scalar leaves and never alters backend logic.
2. Initial host syntax check found OFF native storeByteLanes scalarized while ON keeps an array. The corrected host reads both actual generated ABI layouts; it does not mutate state.
3. First runtime reported LeakSanitizer unsupported under ptrace. Subsequent runs retain ASan/UBSan but set ASAN_OPTIONS=detect_leaks=0. No LeakSanitizer coverage claimed.
4. Initial bare seed0 passed 197 instructions with zero dual/triple witnesses. It was not promoted as three-writer evidence. Aligned input-pair seed1 reached two actual triple edges without forcing any grant or register.
5. Early VM host treated a store followed by a same-packet load as if backing memory were already updated at load allocation. Its architectural expected result was premature. The bounded VM test now drains the first store before that read; the synthetic backing service is explicitly not claimed as an independent general memory-order oracle.
6. Early VM host required storeAddress to hold VA on every virtual store start. A direct head store can start with storeAddressKnown=false and no preceding preparation. The check now requires saved VA only when its original known authority exists, or verifies the next-edge result of an independently authorized simultaneous prep. A later nonhead prepared store is separately required and reached.
7. Early VM host required every ordinary virtual-load replay payload to equal mapped PA. A serial non-prechecked head load legitimately writes invalid load-preparation bits (observed canonicalSignal=0); memoryCanonical remains false. The source eligibility law excludes this row, and orderCheckValid excludes that serial start. The final host checks canonical-authority transitions, separately requires both noncanonical and prechecked starts, checks stored payload only under canonical authority, and independently checks replay valid and oldest winning index. Four actual replay events are reached. This is a correction to an overstrict oracle, not a relaxation of the consumer's valid contract.

No production fix was made for any of these host/fixture issues. Default sharedMemoryAddressState remains OFF. Only the separate negative changes a copied source file, and its classes never enter production or positive classpaths.
