# Historical collection-read head authority: bounded source evidence

This package preserves four isolated historical production-source additions and the exact source of a qualified decoded IntegerBackend test. The seven prerequisite transport/LSU files and selected configuration are pinned in DEPENDENCIES.json to commit 0aed2a377e28ebf956612bf62467687eedaa25a5. Reconstruct the historical 50cb source archive first and apply that transport package, then these four files. Existing repository license/notices apply; retain the source archive's notices.

The production option remains default-off in its prerequisite OooParams. This evidence package does not change the repository's active src/main tree or enable a production profile. Current main is not the tested historical backend: IntegerBackend and MappedMachineCore have other optional-feature changes. Future application must adapt the narrow diff while preserving those features, with a new fresh compile and tests. Do not replace current main wholesale with these historical files.

The actual native test passed 226 cycles and 21 decoded instruction retirements. It establishes one ordinary bare aligned RAM load's authority at the real accepted full-token ROB head, retained request qualification and external store responsibility. It does not establish a complete ISA/exclusion matrix, cache collection progress, frontend timing, Linux performance or board readiness. The jointly integrated cache experiment is separately versioned.

See VERIFIED_OUTCOMES.json and REPRODUCE.md. TESTED_SOURCE_BINDINGS.json identifies byte-exact tested copies. Source-only reconstruction and portable packaging have not been rerun as hardware. No generated model, executable, class file, raw machine-specific manifest or execution trace is included.
