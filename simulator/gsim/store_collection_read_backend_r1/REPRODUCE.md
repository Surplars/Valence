# Reconstruction and validation boundaries

1. Verify the historical archive and prerequisite transport paths/hashes in DEPENDENCIES.json. Retain the license/notices. Apply the prerequisite seven production files, then source/ over the corresponding historical src/main/scala/core/ooo paths. Compile all affected main Scala callers fresh, including case-class constructor callers; do not splice historical objects or classes.
2. Compile the three fixtures in this package against that fresh closure. CollectionReadProfileJson.scala provides the shared profile encoder: do not simultaneously compile another fixture defining the same object. Use the exact dependency config/selected.json. The emitter checks all original named core/profile fields before emission; only postedCollectionReadProgress is added. External DataRequest is184bits; the historical label275 is not its width.
3. With the pinned Java21/Scala2.13.17/Chisel7.3.0 toolchain, invoke ooo.CollectionReadBackendGsimMain OUT true SELECTED. Generate OUT/CollectionReadBackendGsim.fir using GSIM SHA256 f00067c6158db342927ad0d746109ad745298fd4ebe9707fd951998069587116 and --threads=1 --cpp-max-size-KB=512 --dir=OUT. The qualified model had29numbered C++units. Compile every unit fresh with Clang19, -std=c++20 -O1 -fsanitize=address,undefined -fno-sanitize-recover=all. Link host-backend/driver.cpp against those objects with -IOUT and -ldl. No other model is interchangeable.
4. gen_driver.py is a mechanical public FIR/header adapter. Use --help to inspect its explicit FIR/header arguments before regenerating an API receipt; compare its emitted driver and schema to the byte-exact preserved versions. Do not import an old machine-specific receipt. The driver preserves65-bit PMP serialization using an unsigned128-bit intermediate.
5. Run python3 -B host-backend/cases.py --driver RUN --output NEW_DIRECTORY. It executes real decoded initialization/CSRs, store, DIV and head load through actual rename/ROB/LSU machinery, with an explicit independent memory responder. The original guard was96MiB inclusive including all prerequisites,12MiB runtime reserve,800MiB free disk floor,60seconds and1024cycles. Disable core dumps, set ASAN_OPTIONS=detect_leaks=0, reject sanitizer diagnostics, monitor both allocated/apparent bytes and retain timeout/failure evidence. This document is not an automatic resource controller.
6. The two replay wrappers are exact saved-observation source evidence. replay.py retains the original tuple/list comparison failure; replay-r2.py is the corrected qualified wrapper. They deliberately pin the original positive trace/result and local host FREEZE manifest. Those raw trace/manifests are not in this source-only repository package. Without the exact externally retained evidence, the wrappers fail closed; they are not portable fresh-run replay commands. To replay newly generated evidence, create a separately reviewed runner binding rather than modifying these tested copies or claiming the original receipt applies. The original three controls mutate only saved observations and never execute a native DUT.

Qualified source byte identity does not imply a portable reconstruction has been executed. The original hash-bound compile/output/runtime receipts are summarized by their immutable seal identities in VERIFIED_OUTCOMES.json. Broad real-backend recovery/virtual/FP/atomic/forwarding/denial tests and production stack/timing qualification are outside this package.
