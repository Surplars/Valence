Compile all main Scala callers fresh with the archive's pinned build dependencies. Do not use current unrelated CPU sources or stale OooParams/MemoryOperation callers. The original executions used explicit hash-bound compiler classpaths; the newly packaged archive rebuild has not been run.
2. Compile all five fixtures together against that fresh closure. CollectionReadQueueGsim.scala contains the shared CollectionReadProfileJson object; do not add a second copy. Without --dry-run it copies only source/config files to a new directory, preserving byte identity and the test scripts' existing relative binding paths. It never compiles, executes or downloads hardware/tools. Both helper modes are packaging checks, not model qualification.
