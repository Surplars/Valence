# Independent young-load-seal fixtures

Run `python -B simulator/gsim/young_load_seal/verify_fixtures.py --self-test` from
the repository root. It checks every portable host/data input and five shared
source dependencies, regenerates all three directed guest outputs in a temporary
directory, and rejects five hash/fixture mutations. It does not run a DUT.

`directed/` contains the exact seven inputs used for the real OFF/ON directed
CPU execution: independent raw ISA author/interpreter, generated bytes/header,
manifest, C++ observer, trace analyzer and synthetic control checker. To rerun
`offline_selftest.py`, copy that directory to a temporary work directory first;
the script writes a small report beside itself. Its 14 synthetic mutations test
the checker only. The separately recorded 16 mutations of the actual CPU trace
are execution evidence, and are not substituted by synthetic results.

`posted_join_observation/host/` is the full, unchanged 18-file corrected observer
closure. `host-manifest.json` pins the original freeze, exact original 17-file
contract, two changed ledger headers, added helper, and original failure.
`host-only.patch` records that host change. The existing repository tagged
oracle and original historical receipts are untouched.

The COPY guest binary and symbol header in `posted_join_observation/guest/` are
exactly the original A inputs. The original ELF hash is retained for provenance;
its bytes are in the recovery evidence rather than this source package. Rebuild
from existing `simulator/gsim/payloads/cpu_sv39_bandwidth.S` and
`cpu_hot_bandwidth.ld` with the guest-only GCC/objcopy/nm commands in
`simulator/gsim/bound_store_prefetch_cpu.py`. Do not run that complete legacy
benchmark entry merely to recover a guest, since it may generate a DUT model.

`build-contract.json` supplies the exact C++ flags, relative include directories,
translation unit and runtime arguments used with the frozen model objects.
`BoardSocGsim.h` and its matching native object set are explicit external
prerequisites, not missing author inputs. The qualified ON model has 36 native
translation units; OFF uses the original A model. Keep each model's header and
object hashes matched, relink only the copied observer, and compare complete
stdout/AXI/supply output. Generated headers, native model sources/objects,
binaries and raw traces are intentionally retained in the recovery archives.

Original negative CLI options are `--inject-read`, `--inject-memory` and
`--inject-trap`. The four actual-event observation controls use
`POSTED_JOIN_OBSERVATION_INJECT` with `missing-newline`, `fake-join`,
`wrong-cohort` or `wrong-slot`; their required triggers and rejection anchors
are in the host manifest. An absent triggering event is itself a failed control.

`guard.cpp` and `ooo.PostedYoungerLoadSealGsimMain` target the actual production
helper and decode. `owner_cases.py --source <repository> --executable <model>
--output <fresh-directory>` reuses the independent posted-owner fixture and adds
unsealed progress, sticky seal and refill-offer exclusion cases. These component
fixtures do not stand in for the separately qualified CPU execution.
