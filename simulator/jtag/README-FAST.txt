FALLBACK / COMPARISON (explicit; no automatic fallback or replay):
  valence_download_and_run {IMAGE.bin} 0x80200000 safe
Use a fresh board reset/session for each comparison. Safe uses original per-word
address writes and repeated IR/preflight scans; it still prints progress/times.
Both modes require the identical flat binary layout, entry and advertised range.

CHANGES:
- Fast writes use32bit SBA autoincrement; re-seed/check each256-word chunk.
- Fast verification reads every word including zero-padding. Read-on-data can
  start one next read ONLY within the same checked chunk. It is disabled BEFORE
  reading the final word, so no read beyond the file padding or RAM aperture.
- A mismatch drains any bounded one-word read-ahead before disabling side
  effects. Failed drain marks uncertainty; no implicit retry/ABORT/COMMIT.
- USER2 IR is selected once inside a synchronous fast download. No persistent
  IR cache between console commands. Do not interleave another TAP operation
  or native target polling inside that command (this config has no targets).
- A previously checked DONE reply permits omitting a redundant idle NOP. Its
  full capture is checked again while submitting the next operation. Changed
  capture/config, BUSY/error, wrong signature/address or timeout fail closed.
- Full byte-exact readback, CRC, per-word busy/error polling, chunk generation/
  ARMED/link checks and one-shot COMMIT are retained. No memory write/COMMIT is
  replayed; no hard/TAP/system reset is generated by the loader.
- WRITE/VERIFY progress, KiB/s, ETA and WRITE/VERIFY/COMMIT segment times.
  Elapsed excludes host file-read/CRC preparation and ROM verification/execution.
  Effective speed = original payload / (write+full verification+metadata/commit).
- valence_wait_claimed and valence_abort now use absolute Jim namespace variables.
  wait_claimed only observes CLAIM; it is not a run command or execution proof.

VALIDATION (offline, no physical adapter):
- Stock Tcl8.6 AND actual local OpenOCD0.12/Jim independent protocol mocks.
- Safe/fast exact windows,1-byte/odd/1024-boundary/29,296-byte images, delayed
  completion, mismatch drain, failed drain, unsupported controls, generation
  changes, no duplicate transfer/COMMIT, lease release and all old guards.
- Frozen real I1 loader GSIM:48 positive streaming cases and an independent
  negative word oracle. This is SBA RTL coverage, not physical JTAG/cable proof.
- 29,296-byte no-extra-stall census: safe IR132637+DR132637=265274 commands;
  fast IR14+DR59368=59382 commands (77.6% fewer). Full readback in both modes.
  Command counts are NOT a measured board throughput or promised speedup.
